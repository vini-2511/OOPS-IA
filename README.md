# OOPS-IA

## Insurance Claim Management System

This repository contains Java programs demonstrating important Object-Oriented Programming concepts and exception handling using an Insurance Claim Management scenario.

## Members and Programs

### Member-1 – Insurance Claim Management
- Created Claim class with Claim ID and Claim Amount.
- Created MedicalClaim subclass with Hospital Name.
- Demonstrated constructor, inheritance and method overriding.
- Accepts input from the user.
- Output screenshot is included.

### Member-2 – Auto Claim Approval
- Created Approvable interface with approveClaim() method.
- Implemented the interface in the AutoClaim class.
- Accepts claim details and approval choice from the user.
- Demonstrates interface implementation.

### Member-3 – NullPointerException Handling
- Created a Claim object reference.
- Demonstrated an unassigned (null) Claim object.
- Handled NullPointerException using try-catch.
- Displays a meaningful error message instead of terminating the program.
